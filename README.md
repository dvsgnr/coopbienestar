# CoopBienestar

Sitio web estático de CoopBienestar, Santiago, República Dominicana.

## Descripción

Este repositorio contiene los archivos fuente del sitio web estático de CoopBienestar. El proyecto está organizado para mostrar información institucional, servicios, noticias, galería y canales de contacto en una estructura web simple y mantenible.

## Estructura del proyecto

- `index.html`: página principal
- `sobre-nosotros.html`: información institucional
- `servicios.html`: sección de servicios
- `noticias.html`: noticias y novedades
- `galeria.html`: galería de imágenes
- `contactos.html`: información y formulario de contacto
- `404.html`: página de error
- `styles.css`: estilos globales del sitio
- `components.js`: componentes y scripts compartidos
- `img/`: recursos visuales e imágenes del proyecto

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript

## Objetivo

Centralizar y mantener el contenido web de CoopBienestar en un repositorio privado, con una base estática fácil de editar, actualizar y publicar.

## Estado

Proyecto en desarrollo y mantenimiento manual.
